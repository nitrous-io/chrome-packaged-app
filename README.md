# Chrome Package App for Nitrous.IO

Warning: WIP - Still works only with the dev environment.

## Testing

1. In Chrome, bring up the extensions management page by clicking the wrench icon and choosing Tools > Extensions.
   If Developer mode has a + by it, click the +. 
   The + changes to a -, and more buttons and information appear.

2. Click the Load unpacked extension button. A file dialog appears.

3. In the file dialog, navigate to `build/development/compiled` and click OK.
